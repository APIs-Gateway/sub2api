# 常见问题

## {{site}} 和直接用官方接口有什么区别？ {#faq-difference}

接口格式是一样的，客户端里只需要把地址和密钥换成本站的，其他用法不变。能用哪些模型由密钥所在的分组决定，价格见「价格与计费」页，用量在「使用记录」页能查到。

## 支持哪些接口格式？ {#faq-formats}

所有接口共用同一个地址和同一个密钥：

- OpenAI 格式：`/v1/responses`（Codex 使用）、`/v1/chat/completions`
- Anthropic 格式：`/v1/messages`（Claude Code 使用）
- `/v1/models`：查看当前密钥能用的模型

`/v1/embeddings`、图片等接口按密钥所在的分组开放，不可用时会返回 404 或 403。Gemini 原生格式只有 Gemini 分组可用。详细路径见「接口列表」。

## Base URL 要不要加 /v1？ {#faq-v1}

看客户端用哪种接口格式。OpenAI 兼容的客户端（OpenAI SDK、Codex、Cursor 等）填 `{{v1}}`，带 `/v1`。Anthropic 兼容的客户端（Claude Code 等）填 `{{base}}`，不带 `/v1`。各客户端的教程里已经写好了，照抄就行。

## 模型名在哪里查？ {#faq-models}

到「价格与计费」页，按分组列出了每个模型的名称和单价，模型名从那里复制，和页面上的写法一字不差。程序里也可以请求 `GET /v1/models`，直接读出当前密钥能用的模型。

## 支持流式输出吗？ {#faq-stream}

支持。请求里加 `"stream": true` 就行。回复长的请求建议都用流式，否则等待太久，连接可能被中途断开（524）。

## 余额和套餐，先扣哪个？ {#faq-billing-order}

先扣套餐额度。套餐额度用完，或者超出了日、周、月的限额，才会扣余额。两者都没有时，请求会被拒绝，见「错误排查」。

## 在哪里看用了多少？ {#faq-usage}

登录后打开「使用记录」页，每次请求用了哪个模型、花了多少都能查到。「我的订阅」页能看套餐各档额度的剩余。

没登录的时候，也可以打开 [API Key 用量查询](/key-usage) 页，粘贴密钥查这个密钥的用量。

## 密钥泄露了怎么办？ {#faq-key-leak}

马上到「API 密钥」页删除这个密钥，再新建一个，并更新到你的工具里。以后截图或贴配置之前，先遮住密钥。

## 怎么限制一个密钥的花费？ {#faq-key-limit}

在「API 密钥」页编辑这个密钥，可以给它设置总额度和按时间窗口的限额。额度用完后，这个密钥会返回 429，其他密钥和账户余额不受影响。

## 同一个密钥能同时在几个工具里用吗？ {#faq-multi-tools}

可以。同一个密钥可以填在多个工具里，用量都记在这个密钥上。想分开统计，就给每个工具建一个密钥。

## Claude Code 提示认证失败？ {#faq-claude-auth}

先确认配置里用的是 `ANTHROPIC_AUTH_TOKEN`，不是 `ANTHROPIC_API_KEY`。用过官方账号登录的，启动 Claude Code 后输入 `/logout` 退出，然后完全退出并重新打开。如果一直 401，多半是电脑上残留了旧的 `ANTHROPIC_API_KEY` 环境变量，把新密钥顶掉了，删掉它再试，见「错误排查」里 401 的条目。

## Cursor 提示模型名无效？ {#faq-cursor-model}

确认模型名和「价格与计费」页一字不差，已经在 Cursor 的 Models 页里添加并打开，聊天面板里还要关掉 Auto。详见 Cursor 一节。

## 配好了还是连不上？ {#faq-still-failing}

按顺序检查：地址有没有按客户端要求带或不带 `/v1`；密钥是不是完整复制的；改完配置有没有完全退出并重启客户端；终端里有没有残留的旧环境变量。还不行，对照「错误排查」里的现象。

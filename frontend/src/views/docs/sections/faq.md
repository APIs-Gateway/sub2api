# 常见问题

## Base URL 要不要加 /v1？ {#faq-v1}

看客户端用哪种接口格式。OpenAI 兼容的客户端（OpenAI SDK、Codex、Cursor 等）填 `{{v1}}`，带 `/v1`。Anthropic 兼容的客户端（Claude Code 等）填 `{{base}}`，不带 `/v1`。各客户端的教程里已经写好了，照抄就行。

## 支持流式输出吗？ {#faq-stream}

支持。请求里加 `"stream": true` 就行。回复长的请求建议都用流式。

## 余额和套餐，先扣哪个？ {#faq-billing-order}

先扣套餐额度。套餐额度用完，或者超出了日、周、月的限额，才会扣余额。两者都没有时，请求会被拒绝，见「错误排查」。

## 在哪里看用了多少？ {#faq-usage}

登录后打开「使用记录」页，每次请求用了哪个模型、花了多少都能查到。「我的订阅」页能看套餐各档额度的剩余。

没登录的时候，也可以在「密钥用量查询」页（`/key-usage`）粘贴密钥，查这个密钥的用量。

## 密钥泄露了怎么办？ {#faq-key-leak}

马上到「API 密钥」页删除这个密钥，再新建一个，并更新到你的工具里。以后截图或贴配置之前，先遮住密钥。

## 怎么限制一个密钥的花费？ {#faq-key-limit}

在「API 密钥」页编辑这个密钥，可以给它设置总额度和按时间窗口的限额。额度用完后，这个密钥会返回 429，其他密钥和账户余额不受影响。

## 同一个密钥能同时在几个工具里用吗？ {#faq-multi-tools}

可以。同一个密钥可以填在多个工具里，用量都记在这个密钥上。想分开统计，就给每个工具建一个密钥。

## 配好了还是连不上？ {#faq-still-failing}

按顺序检查：地址有没有按客户端要求带或不带 `/v1`；密钥是不是完整复制的；改完配置有没有完全退出并重启客户端；终端里有没有残留的旧环境变量。还不行，对照「错误排查」里的现象。

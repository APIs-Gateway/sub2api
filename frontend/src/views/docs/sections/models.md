# 支持的模型

可用的模型和价格会随时调整，这里不列清单。以「价格与计费」页为准。那一页按分组列出了每个模型的名称和单价，配置客户端时模型名就从那里复制。

你的密钥能用哪些模型，由它所在的分组决定。同一个模型在不同分组里的价格也可能不同。

## 怎么查自己能用的模型 {#models-lookup}

- 在网页上：登录后打开「价格与计费」页，找到密钥所在的分组，那一组下列出的就是能用的模型。密钥属于哪个分组，在「API 密钥」页可以看到。
- 在程序里：用密钥请求 `GET /v1/models`，直接读出当前密钥能用的模型。

```bash
curl {{v1}}/models \
  -H "Authorization: Bearer sk-你的密钥"
```

Windows PowerShell 里用 `curl.exe`，不要用 `curl`：

```bash
curl.exe {{v1}}/models -H "Authorization: Bearer sk-你的密钥"
```

返回的是一个列表，`data` 数组里每一项的 `id` 就是模型名：

```json
{
  "object": "list",
  "data": [
    { "id": "{{model}}", "...": "..." }
  ]
}
```

每一项里除了 `id`，还有 `object` 或 `type`、`display_name` 等附带字段，不同分组略有差别，填模型名只需要 `id`。返回 401 说明密钥没填对；返回 403 且提示分组问题时，到「API 密钥」页给密钥换一个分组。

## 模型名怎么填 {#models-naming}

- 模型名要和价格页或 `/v1/models` 返回的 `id` 一字不差，包括大小写和连字符。
- 不要自己拼写日期后缀，也不要凭记忆写别的站或官方的模型名。价格页上没有的名字，请求会返回 404 `model_not_found`。
- 在请求里，模型名放在 `model` 字段；Codex 等工具写在各自的配置文件里，见对应的教程。
- 模型名会随分组调整。某天突然报找不到模型，先回到价格页确认它还在不在，再看密钥有没有被换过分组。

## 不同客户端的要求 {#models-clients}

| 客户端 | 模型名怎么填 |
|---|---|
| Codex、OpenAI SDK、Cherry Studio 和大多数 OpenAI 兼容客户端 | 直接填价格页上的名字 |
| Claude Code | 直接填价格页上的名字，需要密钥所在分组开放 Claude Code |
| Cursor | 在 Models 页添加自定义模型，名称和价格页一字不差，并确认开关已打开；聊天面板里要关掉 Auto |
| Aider | 名字前面加 `openai/`，例如 `openai/{{model}}`，Aider 靠这个前缀判断走哪种接口 |

客户端里下拉出来的内置模型名，不一定是本站有的。以价格页为准，手动填写。

## 找不到模型怎么办 {#models-trouble}

**报 404 `model_not_found`。** 模型名写错，或者密钥所在的分组没有这个模型。回到价格页逐字对照，或者调用 `/v1/models` 看实际返回的 `id`。

**价格页上有，调用却不行。** 看一下密钥属于哪个分组。同一个模型名可能出现在多个分组里，只有你密钥所在的分组才算数。需要别的分组的模型，在「API 密钥」页给密钥换分组。

**客户端的模型下拉里没有想要的模型。** 很多客户端不会自动读取模型列表，手动输入价格页上的模型名即可。

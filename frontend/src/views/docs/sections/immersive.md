# 沉浸式翻译

[沉浸式翻译](https://immersivetranslate.com) 是浏览器翻译扩展，可以把网页、PDF、视频字幕翻成双语对照。它支持接入 OpenAI 兼容的自定义服务，用你的 {{site}} 密钥即可。

## 配置步骤 {#immersive-steps}

1. 点浏览器工具栏里的扩展图标，进入「设置」，在左侧选「翻译服务」。
2. 找到 OpenAI 这一项（也可以用「添加 OpenAI 兼容服务」新建一个，名称随便填，比如 {{site}}）。
3. 填写下面三项：

| 配置项 | 填什么 |
|---|---|
| API Key | 你的密钥，`sk-你的密钥` |
| 自定义 API 接口地址 | `{{base}}/v1/chat/completions` |
| 模型 | 价格与计费页上列出的模型名，比如 `{{model}}` |

4. 如果界面把地址放在「更多设置」里，先展开再填。
5. 点「测试服务」（或直接翻译一个网页）验证。

> 这里的接口地址要填到 `/chat/completions` 的完整路径，不是只填到 `/v1`。

## 注意用量 {#immersive-usage}

翻译一个网页或一整本书会发出很多请求，长页面、电子书和视频字幕尤其明显。开始前可以先在「API 密钥」页给这把密钥设好额度，用一段时间后再到「使用记录」页看看消耗是否符合预期。

## 常见问题 {#immersive-faq}

- **报 429**：请求太快了。在扩展的翻译服务设置里调低每秒请求数和并发数，电子书翻译尤其要调低。
- **报 404 或 401**：检查接口地址是否是完整路径，密钥是否复制完整。
- **提示模型不可用**：模型要和密钥所在的分组匹配，以「价格与计费」页为准。

## 切回原来的服务 {#immersive-revert}

回到「翻译服务」，把默认翻译服务换成别的即可，这把密钥的配置可以留着，也可以删掉。
